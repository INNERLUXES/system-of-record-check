# A clean map

A made-up integration map of a made-up retailer, Kestrel Valley Outdoor, with four systems: a sales CRM, a finance ERP,
a web shop and a people system. Every entity held by more than one system has one owner, the ERP owns the credit limit
and the payment terms inside a customer that the CRM owns, every copy is fed by a flow from its owner, and the one flow
that writes into the record of another system, the email address the web shop sends back to the CRM, is an approved
exception with a reason. Every system names a team and a contact.

The tool finds nothing in it, with the built-in configuration and with `examples/config.json`.
